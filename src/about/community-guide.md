# 社区指南 {#community-guide}

Vue.js 社区在快速成长。如果你正在读这篇，多半已经准备好加入了。欢迎！

下面说明你能从社区得到什么，以及你能为社区做什么。

## 资源 {#resources}

### 行为规范 {#code-of-conduct}

我们的[行为规范](/about/coc)是一份指南，帮助我们在参与技术社区时相处得更好。

### 保持关注 {#stay-in-the-know}

- 关注[官方 Twitter 账号](https://twitter.com/vuejs)。
- 关注[团队成员](./team)的 Twitter 或 GitHub。
- 关注 [RFC 讨论](https://github.com/vuejs/rfcs)。
- 订阅[官方博客](https://blog.vuejs.org/)。

### 获得帮助 {#get-support}

- [Discord 聊天室](https://discord.com/invite/vue)：Vue 开发者实时聊天、互相认识的地方。
- [论坛](https://forum.vuejs.org/)：问 Vue 及其生态相关问题的好地方。
- [DEV 社区](https://dev.to/t/vue)：在 Dev.to 分享和讨论 Vue。
- [Meetup](https://events.vuejs.org/meetups)：想在本地找 Vue 同好，或想当社区组织者？这里有支持和帮助。
- [GitHub](https://github.com/vuejs)：要报 bug 或提新特性，欢迎提 issue；也欢迎 pull request。
- [Twitter 社区（非官方）](https://twitter.com/i/communities/1516368750634840064)：认识其他 Vue 爱好者、求助或聊 Vue。

### 探索生态 {#explore-the-ecosystem}

- [The Awesome Vue 页面](https://github.com/vuejs/awesome-vue)：社区整理的优质资源列表。
- [Vue Telescope Explorer](https://vuetelescope.com/explore)：浏览用 Vue 做的网站，看它们用了哪些框架和库。
- [Made with Vue.js](https://madewithvuejs.com/)：展示用 Vue 做的项目和库。
- [“Show and Tell” 子论坛](https://github.com/vuejs/core/discussions/categories/show-and-tell)：看大家用 Vue 生态做了什么，以及他们为生态做的贡献。

## 参与方式 {#what-you-can-do}

### 帮助同伴用户 {#help-fellow-users}

贡献代码不是唯一方式。在 Discord 或论坛上帮别人解答 Vue 问题，同样很有价值。

### 协助分流 Issue {#help-triage-issues}

分流 issue 包括：补全缺失信息、复现问题、确认是否有效、查原因等。

[GitHub 仓库](https://github.com/vuejs)每天都会收到很多 issue。和用户量相比，团队精力有限，光是分流就要花不少时间。你帮忙分流，能让团队更高效，把时间用在更优先的工作上。

分流不一定要修 bug（能修更好）。分享你的调查结论，比如导致错误的提交记录，也能帮团队省很多时间。

### 贡献代码 {#contribute-code}

修 bug 或加新特性是最直接的贡献方式。

Vue 核心库有[贡献指南](https://github.com/vuejs/core/blob/main/.github/contributing.md)，包含 pull request 说明，以及构建和架构信息。其他子项目仓库可能也有自己的贡献指南——提 pull request 前请先阅读。

修 bug 我们随时欢迎。新特性建议先在 [RFC 仓库](https://github.com/vuejs/rfcs/discussions)讨论用例和实现细节。

### 分享（并积累）经验 {#share-and-build-your-experience}

除了在论坛或聊天室回答问题、分享资源，还可以：

- **写学习资料**。常说「教学相长」。如果你用 Vue 做了有意思的事，可以写博客、组织研讨会、或在社交平台发 gist——这些都能加深你的理解。
- **关注你关心的仓库**。仓库有新动态你会第一时间知道，能跟上讨论和即将发布的新特性。这是积累专业知识的好办法，久而久之你也能自己解决 issue、提 pull request。

### 翻译文档 {#translate-docs}

希望你现在是用自己熟悉的语言在读文档。如果不是，愿意帮忙翻译吗？

参与方式见[翻译指南](/translations/)。

### 领导社区 {#become-a-community-leader}

在社区里还有很多事能帮 Vue 发展：

- **参加本地 meetup**。无论是分享话题还是组织研讨会，都能帮新老 Vue 开发者成长。
- **自己组织 meetup**。如果本地还没有，你可以发起！可参考 [events.vuejs.org 的资源](https://events.vuejs.org/resources/#getting-started)。
- **帮 meetup 组织者**。办活动需要众人出力，不妨主动帮忙，让每场活动顺利进行。

关于如何参与本地 Vue 社区，有问题可联系 [@Vuejs_Events](https://www.twitter.com/vuejs_events)！
